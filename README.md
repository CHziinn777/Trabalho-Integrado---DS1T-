## 🎯 2. Objetivo do Projeto

Desenvolver uma aplicação desktop interna, leve e autônoma, destinada ao gerenciamento do fluxo operacional de um serviço de delivery.

O sistema terá como finalidade centralizar e agilizar os processos administrativos e operacionais, oferecendo funcionalidades para cadastro de produtos, controle de pedidos e alocação de motoboys.

A aplicação será desenvolvida para operar integralmente de forma nativa, utilizando o interpretador Python e o banco de dados SQLite, sem a necessidade de dependências de terceiros fora da biblioteca padrão do Python.

## ⚙️ 3. Funcionalidades do Sistema

O sistema contará com as seguintes funcionalidades:

- **CRUD de produtos:** cadastro, visualização, atualização e remoção de produtos.
- **Listagem de produtos:** consulta e visualização dos produtos cadastrados.
- **Gerenciamento de pedidos:** agendamento e controle de pedidos.
- **Gerenciamento de entregas:** organização dos dados de navegação dos motoboys e acompanhamento dos pedidos.

## 🚫 4. Escopo Negativo (O que o sistema não fará)

Para manter o projeto dentro de seu escopo inicial, algumas limitações serão estabelecidas:

- Não utilizará sistemas ou serviços de terceiros fora da biblioteca padrão do Python.
- Não será desenvolvido especificamente para uma empresa ou marca comercial.
- Não possuirá acesso externo, sendo destinado exclusivamente ao uso interno de empresas.
